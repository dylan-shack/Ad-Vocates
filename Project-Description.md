## Project Topic Area

  &#x20; Our Senior Design Project will focus on developing a downloadable, privacy focused ad blocker that detects and     blocks advertisments, pop ups, trackers, and suspicious web requests across common websites and search engines. The application will include a user friendly dashboard that displays important diagnostics, such as ads blocked, data saved, and browsing activity. Users will also have customizable protection settings, website whitelistin, and automatic filter updates. The goal is to create a reliable and efficient tool that improves browsing performance while giving users greater privacy, security, and control over their web experience.


## Project Goal

The main goal of Ad-Vocates is to create an ad blocking tool that improves browsing privacy, security, performance, and user control.

Rather than simply blocking content in the background, Ad-Vocates will also provide users with information about the activity being blocked. This will allow users to better understand how advertising and tracking services interact with their browser.

The project will also focus on making the application easy to configure without requiring users to understand the technical details behind web requests or filter rules.

## Target Users

Ad-Vocates is intended for everyday internet users who want more control over advertisements, tracking, and privacy while browsing the web.

The application should be usable by people with little technical knowledge while still providing enough customization for users who want greater control over their protection settings.

Potential users include:

* Users who want to reduce intrusive advertisements and pop-ups.
* Users concerned about online tracking and privacy.
* Users who want websites to load with fewer unnecessary requests.
* Users who want more information about what is being blocked while they browse.
* Users who want the ability to allow ads or other content on trusted websites.
* Users who aren't familiar with how dangerous pop-up ads can be.
