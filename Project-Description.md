\## Project Topic Area

&#x20; Our Senior Design Project will focus on developing a downloadable, privacy focused ad blocker that detects and     blocks advertisments, pop ups, trackers, and suspicious web requests across common websites and search engines. The application will include a user friendly dashboard that displays important diagnostics, such as ads blocked, data saved, and browsing activity. Users will also have customizable protection settings, website whitelistin, and automatic filter updates. The goal is to create a reliable and efficient tool that improves browsing performance while giving users greater privacy, security, and control over their web experience.
